# محاسبه‌گر قیمت کابینت

وب‌اپلیکیشن فارسی و راست‌چین برای برآورد هزینه کابینت آشپزخانه، ساخته‌شده با React، Vite، TypeScript و Tailwind CSS. تمام محاسبات در مرورگر انجام می‌شود و نیازی به بک‌اند نیست.

## اجرا

نیازمندی: Node.js نسخه ۲۰ یا بالاتر و npm.

1. وابستگی‌ها را نصب کنید: `npm install`
2. سرور توسعه را اجرا کنید: `npm run dev`
3. آدرس نمایش‌داده‌شده در ترمینال، معمولاً `http://localhost:5173` را باز کنید.

## ساخت نسخه نهایی

- ساخت: `npm run build`
- پیش‌نمایش خروجی: `npm run preview`
- بررسی تایپ‌ها: `npx tsc --noEmit`
- اجرای تست‌ها: `npx tsx --test tests/calculatePrice.test.ts`

خروجی نهایی در پوشه `dist` قرار می‌گیرد. فایل `dist/index.html` قابل انتشار روی هر هاست استاتیک است.

## نحوه استفاده

- نام پروژه و تاریخ اختیاری هستند؛ تاریخ پیش‌فرض، امروز است.
- قیمت پایه و ضرایب را ویرایش کنید. ضرایب پیش‌فرض: زمینی ۱، دیواری ۰٫۶، ایستاده ۲ و جزیره ۱.
- طول هر بخش را به متر وارد کنید. کسرهای یخچال، گاز، لباسشویی و سایر موارد فقط از طول زمینی کم می‌شوند.
- هزینه صفحه، یراق‌آلات، نصب، حمل، تخفیف و مالیات را در بخش‌های مربوط وارد کنید.
- نتایج زنده به‌روز می‌شوند؛ دکمه محاسبه نیز نتایج را تأیید می‌کند.
- دکمه «ذخیره پیش‌نویس» پروژه را در فهرست پیش‌نویس‌ها ذخیره می‌کند. پروژه فعلی به‌صورت خودکار در مرورگر نگهداری می‌شود.
- «چاپ / PDF» پنجره چاپ مرورگر را باز می‌کند؛ برای دانلود PDF گزینه Save as PDF را انتخاب کنید.
- «کپی فاکتور» متن کامل فاکتور را در حافظه کپی می‌کند.
- «ریست فرم» پس از تأیید، ورودی‌ها را پاک می‌کند اما پیش‌نویس‌های ذخیره‌شده را حذف نمی‌کند.

## فرمول‌ها

- متراژ مؤثر هر بخش = طول آن بخش × ضریب همان بخش
- طول زمینی خالص = طول زمینی − مجموع کسرها
- متراژ مؤثر کل = زمینی + دیواری + ایستاده + جزیره
- هزینه کابینت = متراژ مؤثر کل × قیمت هر متر پایه
- هزینه صفحه = طول صفحه × قیمت هر متر صفحه
- جمع یراق‌آلات = مجموع تعداد × قیمت واحد
- نصب درصدی = هزینه کابینت × درصد نصب
- تخفیف درصدی = جمع هزینه‌ها × درصد تخفیف
- مالیات = (جمع هزینه‌ها − تخفیف) × درصد مالیات
- مبلغ نهایی = جمع هزینه‌ها − تخفیف + مالیات

تخفیف ثابت نمی‌تواند از جمع هزینه‌ها بیشتر باشد. مقادیر منفی در ورودی‌ها مسدود می‌شوند و درصدها باید بین ۰ تا ۱۰۰ باشند. قیمت پایه صفر مجاز است و هشدار نمایش داده می‌شود.

## داده پذیرش

قیمت پایه ۶٬۵۰۰٬۰۰۰ تومان، طول زمینی ۳، دیواری ۳ و ایستاده ۱ متر: متراژ مؤثر ۳، ۱٫۸ و ۲ متر، مجموع ۶٫۸ متر و هزینه کابینت ۴۴٬۲۰۰٬۰۰۰ تومان.

## ساختار

- `src/App.tsx`: مدیریت پروژه، پیش‌نویس‌ها و تعاملات اصلی
- `src/components/CalculatorForm.tsx`: فرم‌ها و اعتبارسنجی
- `src/components/ResultSummary.tsx`: خلاصه فاکتور و خروجی چاپ
- `src/components/AccessoryList.tsx`: مدیریت تجهیزات
- `src/utils/calculatePrice.ts`: تابع خالص محاسبه و اعتبارسنجی
- `src/utils/format.ts`: فرمت اعداد فارسی و تاریخ
- `src/utils/storage.ts`: ذخیره‌سازی محلی
- `src/types.ts`: مدل‌های تایپ‌شده

فونت Vazirmatn از Google Fonts و تصویر معرفی از Pexels بارگذاری می‌شوند. اطلاعات پروژه به هیچ سروری ارسال نمی‌شود.
